Equations & definitions (§4.1)

A1Eq. (6)'s ∞-case tests the wrong point direction-dependent

∞  if  t̃ = tΘ, d < dM

Every non-sink source has d < dM, so the case fires for every leg touching the final time line — including a legal on-time arrival at (L,T). The algorithm and the code accept that arrival; the equation forbids it.

Fix: one tilde — d̃ < dM (test the successor). Disappears entirely if Eq. (6) flips to-arrive.

A2The cell maps price the rectangle behind the vessel

i(d) = argmaxi{ di < d } ,  j(t) = argmaxj{ tj < t }  (strict)

Every DP state sits on a line. With strict inequalities, a state at t = 6.0 h exactly prices its outgoing leg with the forecast block that just expired; a state on a cell boundary prices with the cell it is leaving. The code does the right thing; the definition doesn't.

Fix: weak inequalities (≤) in i(d) and j(t).

A3Solution prose contradicts the cost-to-go equation direction-dependent

"…the minimum fuel to arrive on time at each state (d,t)…"

Under the current cost-to-go Eq. (6), C*(d,t) is the fuel to finish from (d,t) — under the "arrive at" reading, C*(0,0) would be trivially 0, yet the answer is read there. Also: the thing starting at (d,t) is a leg, not a "subsegment".

Fix: "…to complete the voyage from (d,t)…" — or nothing, if Eq. (6) flips to-arrive (the sentence becomes correct as written).

A5"…the following forward Bellman equation" direction-dependent

The recursion that follows is cost-to-go — evaluated backward. Whoever trusts the adjective sweeps it the wrong way (a state's value needs its successors, which forward order hasn't visited).

Fix: drop the adjective — or keep it, if Eq. (6) flips to-arrive.

A4Soft-ETA remark charged a fee no one can incur resolved Aug 4

"Lateness charge λ(t̃−T)" with t̃ ≤ T on the grid — never positive. Now reads "extend the time lines beyond T and charge λ·max(0, t̃−T)".
